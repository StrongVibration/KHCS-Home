최신 · 베타전체 프로그램 시험 결과 반영

정경옥 박사님이 설치본으로 13개 시설의 편람 예제 57건과 추가 시험 20건을 모두 실행해 최종 편람과 대조했습니다. 찾은 쟁점 20건을 이렇게 처리했습니다.

9건프로그램 수정 완료
(2.1.3 · 2.1.4)
3건편람 예제의 중간값 반올림 차이
(프로그램은 중간값을 반올림하지 않음)
8건편람 확인 필요
(프로그램은 편람 본문·표 기준 유지)
  • Excel로 내보낸 수치가 숫자 칸으로 저장됩니다. 합계·정렬을 바로 쓸 수 있습니다.
  • 결과 보고서(Excel·PDF) 머리말에 프로그램 버전을 적고, 신호교차로는 분석 경고를 보고서에 함께 남깁니다.
  • 신호교차로에서 모든 접근로의 교통량이 0이면 분석을 멈추고 교통량 입력을 안내합니다.
  • 허용 범위를 벗어난 값을 직전 값으로 되돌릴 때 그 칸을 노란색으로 표시해, 다시 고칠 때까지 알 수 있게 했습니다.
  • 다른 파일을 열면 창 제목의 파일 이름이 곧바로 바뀝니다.
  • 손상된 파일을 연 뒤 입력자료 정리 화면에 이전 자료가 남던 문제를 고쳤습니다.
  • 2차로도로 계수 파일의 오기(10.734 → 0.734)를 바로잡았습니다. 계산은 원래 맞는 값으로 하고 있었습니다.
  • 엇갈림구간 연결로-연결로 서비스수준 근거를 〈표 4-6〉·〈표 4-7〉로 함께 적습니다.

베타빈 화면 입력 결과 정정
  • 신호교차로를 빈 화면에서 직접 입력해도 편람 예제와 같은 결과가 나오도록 고쳤습니다 (적색신호 우회전 지체).
  • 보행자신호등이 있는 횡단보도에 보행녹색시간이 없으면 0초로 계산하고 입력 검사에서 알려 줍니다.
  • 예제 1 북향 초기대기행렬을 편람대로 차로별 0·12대로 표시합니다.
  • 신호교차로는 네갈래(4지)만 분석할 수 있습니다. 세·다섯·여섯갈래는 개발 중이며, 고르면 안내가 나옵니다.
  • 탭을 여러 번 오가면 화면이 점점 무거워지던 문제를 고쳤습니다.
  • 칸이 비어 있으면 기본값으로 계산하던 곳을 정리했습니다. 이제 칸을 채워 달라고 알리거나, 편람 권장값을 칸에 보여 줍니다.
